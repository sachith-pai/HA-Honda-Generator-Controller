# Smart-Honda-Generator-Controller
Smart Genrator Controller for Honda EU70is using ESPHOME

## Parts Used 
1. [Seeed Studio XIAO ESP32C3](https://www.seeedstudio.com/Seeed-XIAO-ESP32C3-p-5431.html?srsltid=AfmBOooIodbglI-FhdQnmXx7LXcKbdsWosjVKZYqDZ0iIiYKpF8yulmC) 
2. [2 Channel Relay](https://www.amazon.in/Generic-Channel-Module-Shield-Arduino/dp/B099X9H846)
3. [ZMPT101B AC Voltage Sensor](https://amzn.in/d/2pkXmAj)
4. [Push Button](https://robu.in/product/16mm-metal-push-button-waterproof-led-light-self-lock-self-reset-button-1no1nc-orange-color/)
5. Project Box
6. Nylon Hex Standoff & Screws

 
## Features:
- Affordable 
- Voltage Sensing: Uses the ZMBT101B sensor to detect if the AC voltage is 0V (no power) or 220V (mains power).
- Automated Control: Automatically switches the generator ON or OFF based on the sensed voltage using the 2-channel relay.
- Runs on **ESPHome** firmware, making it easy to integrate with **Home Assistant** for seamless smart home control.

## Applications: 
- Automatic power backup systems
- Remote monitoring of generator status
- Seamless integration with **Home Assistant** using **ESPHome** firmware
